# 🏠 DIU Student Smart Home Finder

A web-based platform designed exclusively for **Daffodil International University (DIU)** students to discover **verified hostels and rental homes** near campus with real-time availability, smart filtering, and secure access.

---

## 🚀 Tech Stack

This project is built using the **PERN Stack**, ensuring scalability, performance, and a modern development experience.
